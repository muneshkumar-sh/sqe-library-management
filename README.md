# SQE Library Management System

## Project Description

The SQE Library Management System is a software project developed as part of the Software Quality Engineering course. The project demonstrates the application of software quality practices throughout the software development process using GitHub.

The system will provide basic library management functionality, including managing books, managing library members, and searching for books.

## Project Objectives

* Manage library books
* Manage library members
* Search for books
* Apply Software Quality Engineering practices
* Track project tasks using GitHub Issues
* Organize source code, tests, and documentation

## Main Features

* Book Management
* Member Management
* Book Search

## Project Structure

```text
src/                 Source code
tests/               Test cases
docs/                Project documentation
screenshots/         Project screenshots
.github/             GitHub configuration
.github/workflows/   GitHub workflows
```

## Software Quality Engineering

This project focuses on software quality activities such as requirements management, issue tracking, testing, documentation, and maintaining a structured development workflow through GitHub.
