# SQE Library Management System

## Project Description

The SQE Library Management System is a software project developed to demonstrate Software Quality Engineering practices using GitHub.

The system will provide basic library management functionality, including book management, member management, and book searching.

## Project Objectives

- Manage library books
- Manage library members
- Search for books
- Apply software quality engineering practices
- Track development tasks using GitHub Issues
- Organize source code, tests, documentation, and screenshots
